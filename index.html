Baseware

What is Baseware?

Baseware is an open-source, production-ready SaaS starter with Express 5, strict TypeScript, Prisma 7 and PostgreSQL 16 on the backend and React 19 + Vite 8 on the frontend. It includes HttpOnly-cookie auth with MFA, multi-tenant organizations with invites and RBAC, per-organization Stripe billing, admin panel, audit logs, API keys, Resend transactional email, Docker Compose, Traefik TLS, GitHub Actions CI/CD, Jest tests and docs in Portuguese and English. MIT licensed: no keys, no seats, no tiers.

FAQ

Questions every dev asks before forking

Straight answers, no legalese.

Is Baseware really free?
Yes. Baseware is MIT licensed, with no paid tier, no seats and no license keys. You can use, modify, distribute and sell products built on it.
Can I use it commercially and in client projects?
Yes. The MIT license allows commercial use, modification, distribution and resale. Keep the copyright notice and license text in copies of the source.
Do I have to open-source my app?
No. The MIT license does not require derivative works to be open source. You can keep your product proprietary.
What's the exact stack?
Backend: Express 5, strict TypeScript, Prisma 7, PostgreSQL 16, Zod 4, Winston, Stripe and Resend. Frontend: React 19, Vite 8, React Router 7, CSS Modules and PT-BR/EN i18n. Infra: Node 24, Docker Compose, Nginx, Traefik TLS and GitHub Actions.
How is auth secured?
15-minute access + rotating 7-day refresh in HttpOnly, Secure, SameSite cookies (nothing in localStorage), TOTP MFA with SHA-256 backup codes, bcrypt cost 12, generic anti-enumeration messages, lockout, rate limits on login/reset, reset tokens with SHA-256 hash, single use, 1h expiry, email verification and session listing/revocation.
Does it work well with AI agents (Cursor, Copilot, Codex)?
It was made for that. AGENTS.md is the mandatory build manual, the 5-layer architecture (Route → Controller → Service → Repository → Implementation) stops the AI from scattering logic, and conventions (kebab-case, Conventional Commits, manual DI) keep generated code consistent.
How do I contribute to Baseware?
Open an issue or send a pull request on GitHub. Read AGENTS.md before generating features and keep the English and PT-BR docs in sync.
Where can I get support?
Use GitHub Issues for bugs and feature requests. Baseware is community-supported, and you can sponsor ongoing maintenance through GitHub Sponsors.
