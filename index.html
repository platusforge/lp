DevKit

O que é o DevKit?

DevKit é um boilerplate SaaS production-ready em Express 4, TypeScript strict, Prisma 6 e PostgreSQL 16 no backend e React 18 + Vite no frontend. Inclui autenticação por cookies HttpOnly, organizações multi-tenant com convites e RBAC, cobrança Stripe por organização, painel admin, audit logs, API keys, e-mail transacional com Resend, Docker Compose, TLS com Traefik, CI/CD com GitHub Actions, testes Jest e documentação em português e inglês.

FAQ

Perguntas que todo dev faz antes de comprar

Respostas diretas, sem juridiquês.

Como recebo acesso depois de comprar?
Você informa seu usuário do GitHub no cadastro. Confirmado o pagamento via Stripe, enviamos um convite de colaborador com acesso de leitura (pull) para o repositório privado. O link do repo fica na sua área de cliente e o convite pode ser reenviado quando precisar.
É assinatura ou pagamento único?
Pagamento único: $99 (Starter), $199 (Professional) ou $399 (Team). Acesso vitalício ao repo, sem mensalidade pelo boilerplate. Você só paga terceiros que usar (Stripe, hospedagem).
Posso usar em projetos de clientes?
Sim. A licença permite usar o DevKit como base de SaaS para usuários finais, inclusive comercialmente (plano Team cobre agências). O proibido é revender ou redistribuir o código do boilerplate em si — templates, starters, cursos ou datasets.
Qual é a stack exata?
Backend: Express 4, TypeScript strict, Prisma 6, PostgreSQL 16, Zod, Winston, Stripe e Resend. Frontend: React 18, Vite 5, React Router 6, CSS Modules e i18n PT-BR/EN. Infra: Docker Compose, Nginx, Traefik com TLS e GitHub Actions.
Como a autenticação é protegida?
Access token de 15 minutos + refresh rotativo de 7 dias em cookies HttpOnly, Secure e SameSite (nada em localStorage), bcrypt custo 12, mensagens genéricas anti-enumeração, lockout, rate limit em login e reset, e tokens de reset com hash SHA-256, uso único e 1h de expiração.
Funciona bem com agentes de IA (Cursor, Copilot, Codex)?
Foi feito para isso. O AGENTS.md é o manual de build obrigatório, a arquitetura em 5 camadas (Route → Controller → Service → Repository → Implementation) impede a IA de espalhar lógica, e as convenções (kebab-case, Conventional Commits, DI manual) mantêm o código gerado consistente.
E se eu não gostar? Tem reembolso?
14 dias de garantia incondicional. Pediu reembolso, devolvemos o valor e revogamos o acesso ao repositório. Simples assim.
