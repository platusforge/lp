Privacy Policy (LGPD / GDPR)

Last updated: 2026-09-15. This static landing collects no personal data by itself. Purchases and accounts happen on dashboard.platusforge.com.

Data we process on the dashboard

  • Account: email, name, GitHub username, password hash (bcrypt).
  • Purchase: Stripe customer/session/payment intent ids, amount, status (card data stays with Stripe).
  • Entitlement: product, repo, invite status.

Use

To create accounts, process payments via Stripe, grant/revoke GitHub invites, prevent fraud/double-buy, and provide support.

Rights

Access, correction, portability, deletion via dashboard profile/support. Deletion revokes repo access and removes entitlements; Stripe records are kept for tax/fraud prevention as required by law.

Cookies

Landing: language preference in localStorage only. Dashboard: auth token (see app policy). No third-party trackers on this page.

Contact

Privacy requests via dashboard support with your account email.
